# Brain Get

> **Tri-Platform Agent Skill** for Claude Desktop / Code, Grok CLI, and Google Antigravity / Gemini.  
> Full Untruncated Memory Retrieval by ID — Retrieves full, untruncated content, metadata, links, and lifecycle status of a specific Second Brain memory by its unique ID.

---

## Overview

`brain-get` provides standardized capabilities across conversational AI platforms:
- Zero-truncation content retrieval by memory ID (/brain-get <id>).
- Complete metadata display: volatility, lifecycle status, tags, and timestamps.
- Direct link inspection for immediate graph traversal.
- Tri-platform NTFS junctions connecting Claude, Grok, and Antigravity.
- Standard documentation suite: SKILL.md, HOW_TO_USE.txt, IMPLEMENTATION_PLAN.md, and README.md.

---

## Tri-Platform Architecture

Zero duplicate code across platforms. Canonical source resides in `.agents`:
- **Canonical Source**: `C:\Users\<you>\.agents\skills\brain-get`
- **Claude**: `C:\Users\<you>\.claude\skills\brain-get` (NTFS Junction)
- **Grok**: `C:\Users\<you>\.grok\skills\brain-get` (NTFS Junction)
- **Antigravity**: `C:\Users\<you>\.gemini\config\skills\brain-get` (NTFS Junction)
